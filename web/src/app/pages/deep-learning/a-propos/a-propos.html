Projet Deep Learning · M2 Data Science

DermaPharm AI

Une application web qui réunit deux modèles de deep learning autour de la santé : reconnaître une maladie de peau sur une photo, et prévoir le cours de bourse du laboratoire pharmaceutique Merck.

Réalisé par : NGONO BEPE Marguerite Claudelle Année : 2026
Module 1

Classification d'images de maladies de peau

Réseau de neurones convolutif (CNN) entraîné sur les 5 dernières classes du « 20 Skin Diseases Dataset » (Kaggle) : Tinea, Urticaria, Vascular Tumors, Vasculitis et Warts.

Module 2

Prévision du cours de Merck sur 20 jours

Modèle de série temporelle NeuralProphet (réseau de neurones autorégressif) qui prévoit le prix de l'action Merck (MRK) pour les 20 prochains jours ouvrés, avec un contrôle de fiabilité sur les 20 derniers jours connus.
