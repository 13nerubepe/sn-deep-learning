# Fichiers du modèle

Après la cellule **12-b** du notebook 1, copiez **le contenu** du dossier `export_app/` ici :

| Fichier / dossier | Produit par | Utilisé pour |
|---|---|---|
| `skin_model.pth` | notebook 1, section 12 | les prédictions et Grad-CAM |
| `classes.json` | notebook 1, section 12 | architecture, classes, 7 critères, tableau des CNN |
| `exemples/` | notebook 1, cellule 12-b | images de test cliquables |
| `graphiques/` | notebook 1, cellule 12-b | graphiques affichés dans l'application |
| `merck_prices.csv` | notebook 2, étape 3 | copie de secours des cours de Merck |

Sans `exemples/` ou `graphiques/`, l'application fonctionne : ces sections sont simplement masquées.
