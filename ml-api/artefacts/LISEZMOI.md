# Fichiers du modèle

Copiez ici les fichiers produits par les notebooks :

| Fichier | Produit par |
|---|---|
| `skin_model.pth` | notebook 1, section 12 (poids du modèle retenu) |
| `classes.json` | notebook 1, section 12 (architecture, classes, 7 critères sur le test, tableau de comparaison des CNN) |
| `merck_prices.csv` | notebook 2, étape 3 (copie de secours des cours de Merck) |

La page « Classification d'images » affiche automatiquement les 7 critères et le tableau de comparaison
dès que `classes.json` vient de la nouvelle section 12. Avec un ancien `classes.json`, seuls la prédiction et les scores de base s'affichent.
